# perf-lab — house rules (example)

Put yours at `~/.claude/perf-lab/house-rules.md`; the skill reads it first. Keep it SHORT: only things that went
wrong for you, each with your own words from the moment (the quote is the why).

- Ask before ordering, resizing or cancelling servers — "it's my card"
- Never point a load test at production, not even "a small one"
- Every number in a report links to a raw file — "where did 1,400 come from?"
- Compare only inside one A/B run — "you compared Tuesday's stand with Thursday's"
- Report in tables; corrections stay visible, never silently replace a number
